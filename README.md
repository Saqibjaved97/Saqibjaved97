## 🔬 Research

**The Deployment Gap: Compatibility, Reproducibility, and Runtime Behavior of 1,762 Vision Models in the PyTorch–ONNX–Unity Barracuda Pipeline**

S. A. Haider, **S. Javed**, R. Timofte, D. Ignatov  
Computer Vision Lab, University of Würzburg · 2026 · Manuscript

The study examines the gap between model export and deployment in Unity Barracuda. Although 98.3% of the models export successfully to ONNX, only 46.2% run in Unity Barracuda, showing that many compatibility issues emerge after export.

**Benchmark code:** [ABrain-One/nn-vr](https://github.com/ABrain-One/nn-vr)
